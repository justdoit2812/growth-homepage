项目一：我的成长主页（就是你正在看的这个网站）

个人项目 · 2026.11 · 进行中
  • 解决什么问题：平时学的东西散落在课本、笔记和脑子里，缺一个能长期积累、又能对外展示的地方。这个网站把我的学习过程、技能水平和作品集中到一个链接里，以后找实习或参加竞赛可以直接发出去。
  • 我负责什么：独立完成全部工作——内容组织、页面结构设计、样式编写、交互逻辑、Git 版本管理，并计划长期持续更新。
  • 用了什么技术：HTML5 语义化标签、CSS3（Flexbox 布局 / 响应式设计）、原生 JavaScript（DOM 操作 / 表单校验 / localStorage）、Git。
  • 最大困难是什么：JS 脚本放在 <head> 里导致拿不到 DOM 元素，排查了很久才理解脚本执行时机和 DOM 加载顺序的关系；另外移动端导航栏的响应式布局也调了几轮才满意。
  • 项目收获：第一次完整走通"从零写页面 → 用 Git 提交 → 编写 README"的完整流程；网站上线后会持续更新，把它变成大学四年的成长档案。
