学习记录

从"不会"到"会"的过程。每条记录包含：时间 · 学了什么 · 遇到的问题 · 怎么解决的。

  1. 2026 年 10 月

    学习 HTML 基础与页面结构

    • 学了什么：HTML 常用标签、语义化结构（header / main / footer）、超链接与图片。
    • 遇到的问题：一开始所有内容都用 <div> 堆出来，页面能看但结构很乱，自己也看不懂。
    • 怎么解决的：重读了 MDN 的"HTML 语义化"文档，把网页按"页头 / 主体 / 页脚"重新划分，并用<section>、<nav>替换掉了大部分 <div>。重写之后结构清晰了很多。
  2. 2026 年 10 月底

    学习 CSS 布局：从"调不对"到理解盒模型

    • 学了什么：盒模型、Flexbox 弹性布局、常见居中方案。
    • 遇到的问题：给元素设置了 width 却总觉得"实际占的地方比写的大"，间距怎么调都不对。
    • 怎么解决的：搞清楚了 content-box 和 border-box 的区别——padding 和 border 会被算进/不算进宽度。后来统一加 * { box-sizing: border-box; } 问题消失。
  3. 2026 年 11 月上旬

    学习 JavaScript 基础与 DOM 操作

    • 学了什么：变量与函数、事件监听（addEventListener）、用 JS 修改页面内容。
    • 遇到的问题：脚本写在 <head> 里时，document.getElementById 拿不到元素，一直返回 null。
    • 怎么解决的：查资料明白了"脚本执行时 DOM 还没加载"的问题，把 <script> 放到 </body> 前面就正常了。这个网站的联系表单验证就是用同样的方式写的。
  4. 2026 年 11 月中旬

    学习 Git 与 GitHub 的基本工作流

    • 学了什么：git init / add / commit 的含义、如何推送本地仓库到 GitHub。
    • 遇到的问题：第一次 commit 时报错提示没有配置用户名和邮箱，推送时也不知道远程地址怎么写。
    • 怎么解决的：按报错提示执行了 git config --global user.name 和 user.email；远程推送用 git remote add origin 关联仓库后解决。
    • 还没解决：分支和合并（branch / merge）还只用过一次，多人协作的工作流还不熟练，计划下个月练习。
