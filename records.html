学习记录

从"不会"到"会"的过程。每条记录包含：时间 · 学了什么 · 遇到的问题 · 怎么解决的。

  1. 2026 年暑假

    系统复习巩固 C 语言

    • 学了什么：利用暑假把 C 语言系统过了一遍，重点复习了指针、数组与函数等核心知识点，把大一学得不够扎实的部分补起来。
    • 遇到的问题：指针的部分知识点（指针与地址、指针与数组的关系）当时理解了好一会儿，看书能懂但自己一写就懵。
    • 怎么解决的：通过刷题巩固——同一类指针题目反复练习，做错了就回去对照教材和网上的资料弄懂原理再重写，最后基本能独立写出来。
  2. 2026 年秋季学期（本学期）

    学习数据结构

    • 学了什么：本学期课程学习数据结构：线性表、栈与队列、树、图，以及常见的排序和查找算法。
    • 遇到的问题：还有部分算法没有通过自己写代码复现，目前停留在"看得懂、讲得出"的理论层面，一上手写还是有困难。
    • 打算怎么解决：安排好时间，把没实现的算法逐个用程序写出来验证；等 Python 学完之后，再计划用 Python 把这些算法重新实现一遍，既练算法也练语言。
  3. 2026 年 11 月（本月）

    开始学习 Python 基础语法

    • 学了什么：Python 基础语法：变量与数据类型、流程控制、函数、列表 / 字典等常用结构。
    • 遇到的问题：学完基础语法后，感觉接下来的学习方向有点乱：不确定现在是否应该立刻深入学习下去，还是先把方向定清楚再继续。
    • 还没解决：这个问题暂时没有答案。我打算先了解清楚 AI 应用开发方向具体需要什么，再决定 Python 学到什么程度、往哪个分支深入。
