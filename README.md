> 个人学习记录与技能展示网页 · 陈星（软件工程专业大二）

**在线浏览**：`https://justdoit2812.github.io/growth-homepage/`（GitHub Pages）或直接下载代码后双击 `index.html`
**作者**：陈星 · 正在学习 Python，下一步探索 AI 应用开发

---

## 一、这个网站是做什么的

1. **成长记录**：记录我从"不会"到"会"的过程——学过的东西、踩过的坑、想明白的事；
2. **技能展示**：每项技能都写"我用它做过什么"，有实际作品和代码作证据；
3. **个人名片**：找实习、参加竞赛、申请项目时，直接把这个链接发给别人看。

## 二、页面结构（5 个页面，导航栏互相跳转）

| 页面 | 文件 | 内容 |
|------|------|------|
| 关于我（首页） | `index.html` | 一句话介绍、学习方向、主页定位、最近更新 |
| 学习记录 | `records.html` | 时间线形式，每条含时间 / 学了什么 / 问题 / 解决方式 |
| 技能展示 | `skills.html` | 技能表格（附证据）+ 真实代码片段 + 作品证据 |
| 项目作品 | `projects.html` | 解决什么问题 / 我负责什么 / 技术栈 / 最大困难 |
| 联系方式 | `contact.html` | GitHub（不含隐私信息）+ 留言表单交互 |

## 三、功能与技术

- **纯原生实现**：HTML / CSS / JavaScript，无框架、无 CDN 依赖，离线可完整运行
- **交互功能**（集中在 `js/main.js`，每个功能都有注释）：
  - 当前页面导航自动高亮（对比 `location.pathname` 实现）
  - 移动端响应式汉堡菜单（CSS media query + JS 切换）
  - 留言表单 JavaScript 校验：称呼非空 / 邮箱正则校验 / 留言长度检查，失败红框提示，通过后保存到 `localStorage` 并渲染历史留言，支持清空
  - 回到顶部按钮（滚动超一屏渐显）、页脚年份自动更新
- **样式**（`css/style.css`）：CSS 变量统一配色、Flexbox / Grid 布局、时间线与卡片组件、响应式适配手机

## 四、目录结构


## 五、运行方式

**方式一（最简单）**：解压 / 下载后直接双击 `index.html`，浏览器打开即可，全部功能离线可用。

**方式二（推荐开发时用）**：VS Code + Live Server 插件——右键 `index.html` → "Open with Live Server"。

**方式三（任意静态服务器）**：

```bash
python -m http.server 8000   # 访问 http://localhost:8000
```

## 六、部署到 GitHub Pages

1. 本仓库已推送至 `https://github.com/justdoit2812/growth-homepage`；
2. 仓库页面 → Settings → Pages → Branch 选 `master` → Save；
3. 约 1 分钟后访问 `https://justdoit2812.github.io/growth-homepage/`。
